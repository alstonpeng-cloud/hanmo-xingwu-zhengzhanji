## 一、怎么试玩

Windows 双击 **`启动游戏.bat`**，或在项目目录执行：

```bash
npm start          # 等价于 node tools/serve.mjs，零依赖
```

启动脚本会自动**打开浏览器**，并在命令行里打印真实地址（默认 <http://localhost:8080/>）。
**8080 被占用时会自动顺延到 8081、8082…**，以窗口里打印的地址为准；手机同 WiFi 试玩用窗口里那个 `http://<电脑IP>:<端口>/`。
（必须走本地 http 服务，不能直接双击 `index.html`，因为用了 ES Module。）

**如果浏览器报 `ERR_NO_BUFFER_SPACE` / `ERR_CONNECTION_REFUSED`（连本地服务器都连不上）**：
这不是游戏的问题，是 Windows 的 TCP 栈出问题了（`ERR_NO_BUFFER_SPACE` = 系统 socket 缓冲区不足，此时连 `8.8.8.8` 也会失败）。两种应对：

1. **立刻能玩**：双击项目根目录的 **`三国小兵军团.html`**（单文件版，所有代码内联，**不需要服务器、不需要网络**，建议用 Edge/Chrome 打开）。
   重新生成：`npm run build:html`
2. **修系统网络**（任选，按顺序试）：退出 VPN / 代理 / 加速器（本机装过 TAP 虚拟网卡）和腾讯电脑管家这类带网络防护的软件 → 重启电脑 → 还不行就用管理员 PowerShell 执行 `netsh winsock reset` 与 `netsh int ip reset` 后重启 → 最后用「设置 → 网络和 Internet → 网络重置」。

- 打不开的话看**命令行窗口里的报错**：最常见是「端口被占用」，说明之前开的服务器窗口还没关 —— 关掉旧窗口，再双击一次即可。
- 首页底部四个按钮（铜钱 +1万 / 全员满级 / **全员+1级** / 重置存档）**仅用于本地开发调试，玩家版构建已按  剥离（线上版本不含这些入口）** 。「全员+1级」按一下 = 兵营里每个单位各升 1 级（满级的不动），方便逐级看模型、试合成。
- 存档在浏览器 `localStorage`，键名 `sgxb_save_v1`；点「重置存档」= 删档重来。注意单文件版（`file://`）和服务器版（`http://localhost`）属于**不同来源，存档各自独立**。
- 声音：**主 BGM** 用 `assets/audio/glorious_morning.mp3`（《战争进化史》主题曲，首页 / 战斗 / 结算等页面共用，切换页面只暂停 / 恢复、不重新起播）；**商城 BGM** 用 `assets/audio/bgm_heroic_loop.wav`（英雄主题循环），只进商城时切换。主曲缺失时自动退回英雄循环。首页顶部「声音」打开设置面板，可分别调 **BGM 音量**与**音效音量**（点击 / 拖动滑条），总开关和音量都写进存档。单文件版已把音效与商城 BGM 内联进 HTML，但真实主 BGM 仍按相对路径读取（`assets/` 要和 HTML 放在同一目录）。

15. **索敌修复**：目标死亡的那一帧就立刻重选最近的敌人继续走位，不会再出现「一群人站着不动」的情况。
16. **声音（主 / 商城双 BGM + 音效 + 音量面板）**：**主 BGM**《战争进化史》(Age of War) 的 **Glorious Morning**（`CONFIG.audio.bgm.main` = `assets/audio/glorious_morning.mp3`）覆盖首页、关卡、布阵、兵营、宝箱、每日、战斗和结算——页面切换只暂停 / 恢复缓存播放器，不销毁重建，**尽量不打断音乐**；**商城**单独使用 `assets/audio/bgm_heroic_loop.wav` 英雄主题循环（`CONFIG.audio.bgm.shop`），离开商城暂停、再进从上次位置继续。主曲缺失 / 解码失败时主轨自动换成英雄循环兜底，不会静音。音效共 16 种：通用点击、上阵 / 换位、撤下、合成成功、操作失败、买兵、领奖、开箱、近战挥砍、远程放箭、击倒、虎豹骑冲锋撞击、中毒，以及重做的**胜利 / 失败 / 倒地**音效（古风战鼓 + 编钟 + 竹笛 / 闷鼓 + 古琴残音 + 铜铃，3 秒、无刺耳高音、无人声）；战斗里同名音效按 `CONFIG.audio.gaps` 节流，每个音效最多 3 路复用。首页顶部「声音」打开**音量设置面板**：总开关 + **BGM 音量滑条** + **音效音量滑条**（点击 / 拖动，0~100% 实时生效），`state.audio / bgmVolume / sfxVolume` 全部写进存档。浏览器自动播放限制会在第一次点击后自动恢复 BGM；音效是程序生成的 16kHz 小 WAV，单文件版会内联成 data URI；微信侧走 `wx.createInnerAudioContext`（`build:wx` 会把 `assets/audio` 一起打包）。
17. **黄巾之乱主题战场地图**：斗技场 / 布阵页地面从深蓝网格换成**高饱和黄沙旷野**——沙丘脊线、龟裂、碎石、枯草、断兵、破车，加 4 面带「黄」字的黄巾旗；地形装饰按世界坐标确定性生成（相机拖动 / 缩放会跟着走），中间交战区留白、不遮挡兵种。配色集中在 `CONFIG.arenaTheme`（`sandTop/Upper/Mid/Low`、沙粒、旗面色 / 旗杆色）可随时调。2 倍地图预览：`npm run map:preview` → `docs/preview/huangjin_battle_map.png`（只作预览 / 宣传，不打包进小游戏）。
18. **12 个特殊兵种专用模型 + 每 2 级配件**：按参考图 + 建模提示词重做，每个兵种锁定「1 个主识别轮廓 + 1 个主色 + 1 个核心道具」——先登黑楔子+红竖盾、藤甲圆藤帽+大圆盾、陷阵方铁箱+金边方盾、青州布衣+铺盖卷、白毦两侧白毛、大戟宽肩+超长大戟、青竹斗笠+青竹弓+橙箭囊、元戎横置巨弩、无当尖头巾+红纹盾、幽州白披风轻骑、白马白马+金毛、虎豹黑马+橙色虎纹全包盔。等级配件：Lv3 领巾/腰带/护腕 → Lv5 铁肩甲 → Lv7 胸扣/护膝 → Lv9 头饰金边 + 背后小旗。预览：`node tools/gen-special-preview.mjs` → `docs/preview/special_models.png` 与 `docs/preview/special_models_levels.png`。

**和 PRD 的一处刻意偏差（重要）**：PRD 给的是 盾兵 atk10/def20、弓兵/骑兵同类量级，套进「伤害 = 攻击 - 防御」会让盾兵互打永远是 1 点伤害，战斗必然卡死。所以这里把 1 级攻击抬到防御之上（盾 18/8、弓 25/6、枪 21/7、骑 22/7），公式本身不变，可在 `troops` 里随时调回或重配。

**曲线现在长这样**：`node tools/sim.mjs` 默认是「1 个 seed + 每 20 关抽 1 关 + 城池 / 章节 / 难度档里程碑」的抽样模式（本次 175/2600 个采样关，未抽中的关按首通结算奖励、只跑抽样战斗）。在默认 1 小时挂机假设下，seed 1 本次**卡在第 219 关**（347 场，含 120 场同一关连续重试），全程 282.5 秒；`--full` 逐关全量的 seed 1 跑 427 场卡在第 189 关（277.4 秒），说明 180~220 段确实存在卡点，最终判定仍要用 `--full` 复核。按实测 0.6~0.7 秒/场估算，2600 关全量约 25~35 分钟/seed，旧版 8 seed 默认超过 3 小时。**单场时长**：`simulateArena` 返回的 `result.time` 为固定 1/30 秒步长、200 秒上限的模拟时长；第 600 关参考军实测 **18.7 秒**（`docs/playtest-report.md` 3.1），不是早期文档里的 21.6~25.6 秒。**敌方总战力锚点**（`node tools/power-curve.mjs` 实测）：第 50 关 9,799 / 第 80 关 15,753 / 第 100 关 25,903 / 第 120 关 28,024 / 第 140 关 31,624 / 第 160 关 34,793 / 第 400 关 46,542。`SIM_IDLE_HOURS=0`（完全不挂机）是严格下界，会更早卡住——这正是「缺钱就挂机」的设计出口。想更紧就加 `levelGen.enemiesPerLevel` / 抬高 `levelAnchors`、或把 `specialTiers` 的 `base` / `perLevel` / `cap` 抬高；想更松就反过来调小。

> 模拟里有个坑值得记一下：早期版本是「每次打完就一键合成」，结果兵营被压成 6~7 个单位（远少于 25 个布阵格），斗技场上直接少一半小队，模拟就卡在 15~28 关。**合成本身不增加总战力**（2 个同级 = 1 个高一级，总血量/总输出反而略降），所以正确策略是「先把 25 格站满，多出来的才合」。
>
> 第二个坑：**铜钱只给首通**之后，玩家一旦卡关就没有稳定收入，只能等挂机。所以模拟用 `SIM_IDLE_HOURS`（默认 1）来折算挂机收益；`SIM_IDLE_HOURS=0` 是「完全不挂机」的严格下界，会卡在中后期——这是刻意设计，缺钱时挂机就是唯一出口。
>
> 第三个坑：**只按战力选 25 个上阵会把阵容选歪**（某些种子会攒出 15 支骑兵、几乎没有前排），所以在模拟里把近战限制在 15 个、弓兵限制在 10 个，近战不够时弓兵补位——这也和界面上手动布阵的思路一致。

## 五、美术：精灵表规格与替换

### 规格（和你说的一致）

- 一张精灵表 = **一个兵种的一个档位**，网格 **4 列 × 4 行**，单帧 **96×96**，脚底基准线 y=86。
- 行顺序固定：`idle`（待机）→ `attack`（攻击）→ `hit`（受击）→ `death`（死亡），**列不够就留空**。
- 朝向：素材一律**朝右**，敌方由渲染层水平翻转。
- 文件命名：`assets/sprites/<兵种>_<档位>.png`，档位 1~10（= 等级 1~10），例：`shield_1.png` … `shield_10.png`、`spear_1.png` … `spear_10.png`。

| 虎豹骑 | 奔袭破阵（被动）+ 龙胆虎威（技能） | 开局双倍移速冲锋（只 1 次），撞上第一个敌人造成 **4 倍**撞击伤害；开战给自身与周围 6~10 个单位加攻速 3%~60% |

**战场上的可视化（`src/screens/battle.js`）**

- **虎豹骑冲锋**：冲锋途中身后拉出淡蓝**速度残影 + 速度线**；撞上敌人时地面炸开**金色冲击波**（双层扩散环 + 中心亮斑），飘「冲锋撞击」金字与真实伤害。
- **无当飞军毒矢**：箭矢变**绿色**；命中时一圈**绿色毒雾**扩散 + 气泡；中毒的兵脚底泛绿光、头顶持续冒绿色气泡（每 0.5 秒结算一次绿色毒伤飘字）。
- **加攻击的增益（陷阵 / 血怒）**：脚下一圈**红色脉冲光环** + 身上红色辉光 + 往上飘的红色火屑。
- **加攻速 / 冲锋 / 突刺**：脚下一圈**青白色旋转风环**（龙胆虎威 + 大戟士突刺都有），配合速度线。
- **闪避（屏卫掩护）**：脚下**青色涟漪**一圈圈扩散；真的闪掉时飘「闪避」而不是伤害数字。
- **反击**：反击伤害飘字下方标「反击」；被击倒的单位照旧倒地淡出。

**顺带修的 bug**

- **目标死亡后不再站桩**：以前每 0.45 秒才全量重选一次目标，锁定的人一死，这一帧就把 `targetId` 清空、`moving = false`，看着像发呆；现在每帧检查当前目标，**一旦目标死亡立刻 `pickTarget()` 改打下一个最近的敌人并继续走**（白马义从会优先挑敌方弓兵）。回归断言在 `tools/test.mjs`（「目标阵亡后立刻改打下一个敌人」）。
- 顺带修了**多个陷阵营光环叠加**的问题：同名增益改为「取最大值」，不会 4 个陷阵营把攻击力叠成天文数字。


### 两个自动兜底（改立绘时不用自己量像素）

- **出框自动纠正**：每帧先在 192×192 的「探针画布」上试画（格子左上角偏置 48，所以连画到邻格的内容也能测到），扫 alpha 包围盒；超出 96×96 的格子就按脚底锚点缩放 + 平移回格内（留 2px 边）。死亡倒地、枪兵突刺、骑兵冲锋这些大位移帧也永远不会被裁掉半个头。
- **逐帧裁切自检**：`node tools/check-bounds.mjs` 把每张表逐格扫一遍，贴边（`x<=0` / `>=95`）就报出来；当前 **160 张表 / 1480 帧全部在画布内**（40 张普通 PNG + 12 个特殊兵种 × 10 档内存表）。
- 单看某个兵种某一档：`node tools/_dbg.mjs spear 7 idle,attack,death` → 3 倍放大图输出到 `assets/_smoke/dbg_spear_7.png`；**特殊兵种也能用**（`node tools/_dbg.mjs baier 3 idle,attack`，没有 PNG 就现画内存表）。

### 怎么换成真实美术

1. 把画好的 PNG 按上面的命名丢进 `assets/sprites/`（覆盖现有文件）。
2. 什么都不用改：`sprites.js` 会先尝试加载 `assets/sprites/<兵种>_<档位>.png`，加载成功就用图，**加载失败/不存在自动回退到程序化占位图**，不会白屏。
3. 改完执行 `node tools/build-wx.mjs` 重新生成 `wechat/`（美术资源会一起打包）。

### 重新生成占位图（改配色/造型时）

```bash
npm run sprites     # 输出 40 张普通兵种 PNG + atlas.json + _preview_all.png / _preview_actions.png / _preview_special.png
```

`assets/sprites/_preview_all.png` 可一眼看到 16 兵种 × 10 档的全部外观（左侧标了 Lv），`_preview_actions.png` 是 4 个普通兵种 Lv10 四动作逐帧放大对照，`_preview_special.png` 是 12 个特殊兵种 Lv10 的对照。

> 普通兵种走第二版哑光土色板（`sprites.js` 的 `paletteFor` → `TONES`）：盾 = 墨灰、枪 = 墨绿、弓 = 土黄、骑 = 赭石，只从赭石 / 褐 / 土黄 / 苍黄 / 墨绿 / 墨灰这一档取色（饱和度 6%~18%、明度 31%~40%）。**10 个等级同色系**：升级只加装备、饰件与材质，主色和皮革 / 铁 / 铜 / 马色都不随等级变亮，一屏不会出现「一级一个颜色」。红色、蓝色、白色、亮绿、紫色，以及会读成蓝紫的黛青 / 藕荷，还有与稀有及以上兵种识别色相近的金黄、象牙白、蓝灰、翠绿、青绿、暗红，全部不用。品级色与英雄建模不走这套色板。

> 英雄单位还留着 `heroSlots` 和战斗/兵营的展示位，但**没有英雄代码**；后续加英雄时按同样规格做一套 `hero_*.png` + 在 `troops` 里加一条配置即可。

## 九、已知限制 / 下一步

- **主 BGM 说明**：`assets/audio/glorious_morning.mp3`（约 1.35 MB）已在包内，主轨覆盖首页 / 战斗 / 结算，商城单独用英雄循环；页面切换只暂停 / 恢复、不打断。如需换成自有曲目，同名替换即可（InnerAudioContext 支持 mp3/m4a/wav，非常规编码可能解码失败并回退）。详见第七节。
- **英雄系统已实装**：12 名英雄、招募 / 升级 / 3 个上阵位（200 / 500 / 1000 关依次解锁第 1 / 2 / 3 位），布阵页英雄卡与普通兵牌混排、可拖拽上阵；「过 5 关斩 6 将」开跑前也走同一套布阵页，冲锋快照会带上阵英雄。
- **关卡内容单一**：2600 关只有兵种排列与等级差异，没有 Boss 关、特殊机制、关卡目标（守城/限时等）。关卡是公式生成的（`levelDef(n)` 按 `levelGen` 算数量/等级/排列），继续加关只需把 `chapters` + `levelGen.total` 一起扩大；征战页的「接下来 25 关」奖励窗口会自动翻页。
- **战斗不可操作**：进场后全自动，玩家能操作的只有布阵（谁在前排在前面、弓兵放后排）；后续若要加手动技能/冲锋指令再扩。
- **AI 只有一条规则**：所有兵都是「找最近的敌人打」，没有盾兵顶前排、弓兵风筝、骑兵绕后切弓兵这类兵种策略；要加可以在 `core/arena.js` 的 `retarget()` 里按兵种分别选目标。
- **精灵表内存**：按需生成并缓存（4 个普通兵种 + 12 个特殊兵种 × 10 档，只有用到的档位才会进缓存），低端机若担心内存可在切场景时清理缓存（`sprites.js` 里 `cache` / `customSheets`）。
- **商城只到 Lv6**：商城目前只卖 Lv1 / Lv3 / Lv6（价格 2^(lv-1) 倍，再高就贵到没意义），Lv7~Lv10 只能靠自己合成；如果想让玩家用铜钱追赶，可在 `CONFIG.shop.levels` 里加档并把 `economy` 一起放大。
- **普通敌人最高只到 Lv5（架构上仍支持 Lv10）；英雄 BOSS 另有 1~30 级成长**：普通小队等级由 `levelGen.levelAnchors` 锚点插值算（第 1 关 1.0 → 第 50 关 1.3 → 第 80 关 2.3 → 第 100 关 2.49 → 第 200 关 3.3 → 第 400 关 4.2，小数部分 = 这一关升 1 级的小队比例），第 400 关显示 Lv4~5、总战力约 46,500；英雄 BOSS 从第 150 关起每 10 关出现，等级按 `heroBoss.levelBase + floor((n - from) / levelStep)` 成长并封顶 30（2600 关为 Lv27）。因为前 400 关的常规箱是「每 5 关一个小木箱 + 20/50 关叠加银/金」，宝箱总数变少但单箱品质更高，玩家兵种成长节奏重新跑过 `sim`；Lv7~Lv10 的铁皮甲/精锐/老兵立绘目前只出现在玩家这边。以后想展示可以加「精英关 / Boss 关」，或者抬高 `levelAnchors` 并用 `sim` 复验。
- **宝箱 5 档 + 特殊 3 档，铂金 / 玄玉先占位**：常规顺序 小木 → 银 → 金 → 铂金 → 玄玉，前 400 关只掉前三档；`platinum` / `jade` 在 `chests.types` 里已经占好位置（`locked: true`、空掉落表、配色已定：玄玉 = 暗青带墨 `#3f7369`），第二章之后填好 `drops` 并把 `locked` 去掉即可。
- **敌方已混编稀有 / 史诗 / 传奇**：广宗 101 关起稀有、颍川 201 关起史诗、宛城 301 关起传奇（`levelGen.specialTiers`），同一兵种线替换；比例随关卡上涨并封顶（第 400 关约 25% 的小队是特殊兵种），不会出现「清一色特殊兵」。
- **特殊兵种不能和普通兵合成**：合成要求「同兵种 + 同等级」，所以青州兵只能跟青州兵合、不能吃普通枪兵；兵营满了又没配对时，靠首通宝箱 / 挂机铜钱 / 商城补兵，或者先合成腾格子（没有遣散）。
- **品级只影响 1 级基础属性**：`rarityStats` 只乘 1 级 hp/atk/def（稀有 +35% / 史诗 +85% / 传奇 +185%），成长率与普通兵相同；如果想让传奇在后期更碾压，得给特殊兵种单独写成长率（`SPECIAL_TROOPS` 里加 `growth` 覆盖）。
- **战力是估算值**：`core/power.js` 用「队血 + 队秒伤×3 + 防御×2」折算，不模拟集火、射程先手、闪避、冲锋节奏，所以会出现「战力略高却打不过」（尤其青竹弓手这种人多、单兵弱的阵容）。它适合做难度参考，真实胜负仍要看克制与布阵；想更贴近实战可以给远程/突进再加权重。
- **本局最佳只记录小队级数据**：输出/承伤/击倒按「一个小队」累计，不区分小队里具体哪个兵；也没有回放或逐帧日志。要按兵统计可以把 `arena.js` 的 `squadStats` 换成 `entityStats`。
- **时间防篡改（v1.0.34 已加固）**：所有发奖计时统一走 `core/clock.js` 的 `now()` —— 会话内单调（`performance.now` 差值）、启动用存档 `lastSeen` 高水位钳制、微信端异步拉 `wx.getServerTime()` 校准。改本机 / 地区时间不再能反复吃满挂机或跨天刷每日 / 广告 / 签到。**边界**：纯单机无服务端签名，越狱改存档本身仍可伪造数值；若要彻底防刷需服务端校验。挂机单次封顶 8 小时的规则不变。
- **铜钱出口只有商城买兵**：铜钱现在只能买 4 个普通兵种（Lv1/Lv3/Lv6），没有抽卡、装备、升级建筑等其它消耗渠道；稀有兵种靠每日任务 / 签到 / 7 日登录稳定攒，史诗 / 传奇主要靠金箱与章节里程碑，所以铜钱在后期会偏富余，后续加新系统时记得一起做新的出口。
- **待补内容**：7 日登录第 3~7 天奖励（现在是稀有箱×2 占位）、史诗宝箱的额外获取渠道（竞技场 / 限时活动 / 列传副本）、铂金箱与玄玉箱的概率表、关卡 Boss / 词缀机制（2600 关目前仍是兵种排列 + 等级差异；第 5 关已有幽州突骑支援剧情这一种剧情关）。**英雄系统（3 武将位）、新手引导、每日任务 / 签到 / 关卡进度条 / BGM 与音效均已完成**。
