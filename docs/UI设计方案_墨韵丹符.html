墨韵丹符

一张摊开的汉代军策：以简为骨，以丹为魂，以金为赏。

本方案为 微信小游戏 量身设定。核心策略是 让颜色直接承担功能导航——玩家不必读文字，仅凭色相就能分辨「这是打胜仗、这是吃败仗、这是花钱、这是开箱」。整体基调从旧版的暖褐转向 冷冽玄墨 + 丹砂符印，更沉稳、更高级，也让四大系统的语义色真正立得住。

壹 · DIRECTION

设计方向：玄墨为底，丹符点睛

旧版「暖褐 + 暗金 + 雕花边框」氛围到位，但所有系统共用一套色调，功能只能靠文字辨认。本方案保留国风骨架，把基调换为冷冽玄墨，并用四个高辨识度色相把系统彻底分开。

「一张军策，四色定乾坤：
金记功，铁记败，蚨记市，紫记藏。」

视觉隐喻取自汉代的竹简、军符与 sealing 印章：信息像写在简牍上，关键动作像盖下一枚朱砂符印。冷调底色让金黄色奖励与朱砂按钮更跳，长时间游玩也更护眼。

一

简牍为骨

面板用竖向竹简纹理与细描边构建秩序，去掉繁复雕花，减少绘制开销。

二

丹符为魂

朱砂印章作为品牌记忆点，只用在最高层级的操作（出战、盖章确认），不滥用。

三

四色定性

成功/失败/商城/宝箱各占一个色相，形成「颜色 → 功能」的肌肉记忆。

贰 · COLOR SYSTEM

色彩系统：一眼辨功能

这是本方案的核心。四类系统各占一个独立色相，互不撞色；中性色统一带冷青倾向，与品牌丹砂形成内在呼应。所有色值可直接落为代码常量，无需图片。

基调中性 · 玄墨阶

深色模式不靠纯黑。带一点冷青倾向的中性色让玄墨有"铁"的质感，也让叠在其上的金/朱/紫更纯正。面块越靠前越亮（surface 提升用明度，不用阴影）。

四大语义色 · 你要的答案

成功用暖金（封赏、凯旋），失败用冷玄铁（收敛、沉寂），商城用青蚨铜绿（市井交易），宝箱用紫气（珍藏、开运）。失败刻意避开大红——在国风语境里红色属于喜庆与品牌印章，用冷灰蓝表达失败反而更克制、更高级，也避免了"红既是喜又是败"的语义冲突。仅失败标题保留一抹残赤点睛。

兵种品级色 · 跨系统通用

品级色只用于"物"（兵牌边框、详情面板、条形数值），不用于系统级按钮，避免与四大语义色打架。这样玩家看到紫色边框 = 史诗兵，看到紫色页面 = 宝箱，语境清晰。

柒 · 4MB BUDGET

4MB 落地规范（硬约束）

微信小游戏主包限制 4MB——视觉方案必须"用代码画画"。本游戏已有程序化国风建模的良好基础，只要守住下列原则，视觉升级几乎不增加包体。

资源类别策略预算
代码（逻辑+渲染）纯 JS，无框架运行时~600 KB
字体系统字体栈，0 字体文件0 KB
UI 图 / 图标程序绘制 + 极简雪碧图~150 KB
兵种精灵运行时程序化生成，真图可选覆盖~500 KB
背景 / 纹理渐变 + 噪点算法生成~80 KB
音频（BGM+音效）BGM 80kbps MP3，音效 16kHz WAV~900 KB
配置 / 数据章节公式生成，不硬编码 2600 关~120 KB
合计 / 预留保留缓冲给后续内容≈ 2.35 MB / 4 MB

示意：已用约 59%，预留约 41%（含分包/缓冲）。

零字体文件

中文衬线/黑体走系统栈；若必须自定义，仅子集化用到的汉字（通常 <40KB），绝不打包整字库。

纹理程序化

竹简竖纹、印章肌理、黄沙地形用 Canvas 渐变 + 噪声算法运行时绘制，替代位图贴图。

图标矢量化

图标用 路径绘制或单色雪碧图；同一图标只存一份，靠 tint 复用出四种语义色。

色值即常量

全套配色写成 JS 常量表，与代码共享；改主题只改一处，零资源增量。

音频先压缩

沿用现有 80kbps BGM / 16kHz SFX 方案；优先分包加载非首屏音频。

分包与按需

低频内容（演武/兵书/后期章节素材）走分包或运行时生成，主包只放首屏必需。

捌 · ACCESSIBILITY

无障碍与易用性

好界面不止好看。以下标准在小游戏环境下同样执行，尤其照顾单手操作与色觉差异玩家。

◉

不靠颜色单独传意

语义色同时配文字标签与图形符号（如"首通奖励"标签、宝箱品级图标），红绿色觉差异玩家也能理解。

手

触控热区 ≥ 88px

移动端主按钮不小于 44pt 的 2 倍安全区；拖拽合成的目标框留足容差，防误触。

≈

尊重减弱动效

开箱、盖章等动效可关；提供静态替代，避免高频闪烁（尤其鎏金爆点）。

玖 · HANDOFF

开发交接：可直接复制的令牌

下列常量同时适用于 Web（CSS 变量）与微信小游戏（JS 常量 / Canvas 绘制）。渲染层读取同一份色表，保证设计与实现一致。

/* 语义色 · 一眼辨功能 */
--victory: #E8B44C; /* 成功 / 凯旋 */
--defeat: #5B6B78; /* 失败 / 玄铁 */
--blood: #A6433A; /* 残赤 · 仅点睛 */
--shop: #3E9A85; /* 商城 / 青蚨 */
--treasure:#9B77CF; /* 宝箱 / 紫气 */
--seal: #B93A2E; /* 品牌 / 丹砂 */
/* 中性阶（冷玄墨） */
--bg:#12171B; --panel:#1F262C; --line:#313C45; --text:#ECF1F4; --text-dim:#8C9BA7;
/* 品级 */
--r-common:#8C9BA7; --r-rare:#5B9BD5; --r-epic:#A971D6; --r-legend:#E8B44C;

落地提示：在 src/data/config.js 增加 UI_THEME 常量对象，渲染层（render/draw.js 与各 screens）统一引用；换肤时只替换该对象，不动任何绘制逻辑。
