五、本轮真实落地项

  • 建模：12 张 Q 版 3D 英雄立绘接入 drawHeroFigure()，影响英雄 / 招募 / 布阵 / 战场 / 结算等 8+ 界面。
  • 建模：6 种 3D 宝箱接入 drawChest()，图标尺寸由 118×104 放大到 152×134；开盖动画仍走程序化保证盖子会掀。
  • 建模：5 张 3D 器械接入 drawEngineFigure()，并在兵营「器械」弹窗新增器械图谱，5 张全部真实出镜。
  • UI：5 张全屏背景插画按屏幕 artBg 专属分发；结算页补齐 artBg = 'result'。
  • UI：新增 carvedFrame() 云纹角花与 goldDust() 确定性金粉，铺到首页、商城、宝箱、招募、结算五屏。
  • UI：商城特殊宝箱补传 kind，改用 3D 贴图而非程序化箱体。
  • 分包：packageArt.js 统一资源路由，分包未就绪 / 图片加载失败 / Node 单测一律回退程序化绘制。
  • 工具：prepare_art.py 重建抠图算法（背景色场 + 中性/暖白双判据 + 区域生长），修复关羽等大片白底。
  • 工具：tools/smoke.mjs 同步预加载分包素材，197 张截图均为真实位图渲染而非兜底。
  • 工具：verify-wx-pack.mjs 修正板块 1 遗留断言：改为检查模拟素材零残留 + 真实 heroes 分包完整保留。
  • 包体：主包 3.61 → 2.34 MB，BGM 与全部美术迁出；总包用至 29.09 MB / 30 MB。
