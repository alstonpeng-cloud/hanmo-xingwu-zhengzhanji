S0.3-2设计语言总纲（12 屏共用）

① 背景与光效

  • 深褐近黑底，顶部暖金放射光晕（斜上方打光），四角暗角压暗
  • 金色粒子星尘散布（首页、每日挑战、每周挑战最密）
  • 底部祥云暗纹 / 卷云浮雕，部分页面四角有青绿玉雕祥云角花（战败页最明显）
  • 页脚固定：上下双细金线 + 居中金字「汉末行伍征战记」

② 边框与纹样

  • 双层金线：外层亮金 + 内层暗金细线，圆角约 10–14px
  • 四角中式云纹 / 回纹角花（一级按钮、英雄卡、每周挑战格、卷轴）
  • 选中态：金色外发光 + 粒子 + 内高光条
  • 禁用态：灰褐底 + 暗金线 + 降透明度

③ 字体层级

  • 大标题：毛笔书法体（飞白笔触）+ 金色渐变 + 暗描边 + 光晕
  • 页面标题：书法感宋/楷，24–34px，暖金
  • 卡片名：18–22px 暖金；正文 13–15px 米白；辅助 11–13px 暗米
  • 数值：等宽或加粗，金色高亮；进度/百分比用绿或朱红

④ 按钮体系

  • 一级：朱红渐变 + 金边 + 四角云纹角花 + 内发光（闯关/出战/挑战/扫荡/重新挑战）
  • 次级：深褐底 + 金边 + 金色书法大字（继续挑战/一键合成/开箱）
  • 三级：暗褐底 + 暗金细线 + 米白字（返回/去宝箱页开箱）
  • 功能：冷蓝灰 / 紫色 / 金色胶囊，按系统区分

⑤ 建模语言

  • 兵模：低多边形小人，有明暗面、地面投影、装备识别（盾/弓/枪/马/弩车），成方阵排布
  • 英雄（招募）：低多边形 3D 小人 + 金色圆形底座光环 + 暖光侧打
  • 英雄（每日）：写实厚涂武将立绘，黑金铠甲、侧逆光、烟尘
  • 宝箱：3D 渲染质感，木纹 / 银 / 金 / 紫 / 红，金属包边与高光

⑥ 版式

  • 竖屏 9:16，安全区左右各约 24px
  • 顶栏三件套：返回（左）+ 标题（中）+ 货币（右），下方一道细金线
  • 内容区：分组标题 + 卡片网格（2/3/4/5 列按屏适配）
  • 底部主行动按钮固定，页脚信息条独立

S0.3-4三类要素分级（诚实的技术边界）

参考图是 AI 生成的渲染级视觉稿。为了让「完全复刻」有可验收的定义，把 12 屏的所有视觉要素分成三类：

A 类可精确复刻

Canvas 代码直接绘制，可做到与参考图一致。

  • 布局、栅格、间距、卡片尺寸
  • 全部色值与渐变方向
  • 边框层数、圆角、描边粗细
  • 文字层级、字号、字重
  • 进度条、数据排版、品级色
  • 按钮形状与状态（选中/禁用）

B 类分层渐变逼近

程序化可做到 80–90% 观感，细节需取舍。

  • 书法标题：系统楷体 + 描边 + 金渐变 + 轻微倾斜（笔触飞白无法 1:1）
  • 顶部放射光晕、金色粒子星尘
  • 云纹 / 回纹角花（SVG 路径近似）
  • 朱红卷轴、青绿玉雕祥云
  • 金属渐变、暗角、内外发光
  • 兵模明暗面与投影

C 类必须分包贴图

靠代码无法生成，需 AI 生成图片并置于分包。

  • 写实厚涂武将立绘（图 08）
  • 低模 3D 英雄小人（图 09）
  • 3D 宝箱图标 5 种（图 10/07）
  • 兵种/器械高精贴图（按需）
  • 书法字帖字形（若要求 100% 笔形）
结论：A 类必须 100% 达标；B 类以「整体观感一致、无违和」为验收线；C 类以「分包下载后立绘到位、下载前 fallback 不塌陷」为验收线。这样每屏验收都有明确尺度，不会出现「说不清像不像」的扯皮。

每屏验收 checklist（12 屏通用）

A 类 · 必须 100% 一致

  • 整体底色为暖褐（无冷灰蓝残留）
  • 顶栏三件套位置与金线分隔
  • 卡片数量、网格列数、间距一致
  • 主按钮文案、层级、位置一致
  • 品级色：金/紫/蓝/绿/灰对应正确
  • 页脚双金线 + 游戏名居中

B 类 · 观感一致

  • 标题为书法感金字 + 描边 + 光晕
  • 顶部暖金聚光与四角暗角
  • 双层金边与四角云纹角花
  • 金色粒子星尘（该有的屏必须有点）
  • 朱红按钮内发光与上沿高光
  • 兵模有明暗面与地面投影

C 类 · 分包资产

  • 立绘/小人/宝箱贴图到位且清晰不糊
  • 分包未下载时 fallback 不塌陷、不空白
  • 下载完成后无闪烁替换
  • 透明底正确，无白边黑边

功能与包体

  • 逻辑测试全绿（1625 断言基线）
  • 冒烟 90 断言 / 235 截图无报错
  • 主包 ≤ 4 MB、总包 ≤ 30 MB
  • 分包失败/断网时核心玩法仍可继续
  • 存档、音频、购买、招募、开箱、结算无回归
